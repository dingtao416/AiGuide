# 什么是 AI Agent

> "ChatGPT 是一个能回答问题的大脑，Agent 是一个能替你干活的员工。"

## 🎯 开篇：同一个需求，两种完全不同的体验

假设你对 AI 说：

> "帮我订一张下周三去上海的机票，要东航的，500 块以内。"

**普通 ChatGPT 的回答：**

```
好的！以下是一些订票建议：
1. 你可以访问携程、去哪儿等平台搜索航班
2. 东航官网通常有直销优惠
3. 建议提前 3-5 天预订以获得更好的价格
4. 你可以拨打东航客服 95530 查询...

需要更多帮助请告诉我！
```

很有礼貌，但**什么也没做**。你得到了一堆"建议"，然后还是要自己去订。

**AI Agent 的做法：**

```
正在执行...
  ✅ 搜索 3月28日 北京→上海 东航航班
  ✅ 找到 3 个符合条件的航班：
     MU5101 07:00 ¥420 | MU5137 12:30 ¥460 | MU5181 18:00 ¥380
  ✅ 最便宜的是 MU5181（¥380），符合预算
  ✅ 已使用您的常旅客信息填写订单
  ⏸️ 待您确认后完成支付

是否确认预订 MU5181（18:00 出发，¥380）？
```

它**真的去查了航班、比了价格、填好了订单**，最后等你确认。

**这就是 Agent 和普通 AI 的本质区别**：
- ChatGPT 是**顾问**——告诉你怎么做
- Agent 是**员工**——直接替你做

## 01｜Agent 的定义

### 一句话定义

> **AI Agent（智能体）= 一个能自主感知环境、做出决策、采取行动来完成目标的 AI 系统。**

关键词拆解：
- **自主**：不需要人类每一步都指挥
- **感知环境**：能读取信息（网页、文件、数据库、用户输入……）
- **做出决策**：理解目标，制定计划
- **采取行动**：调用工具、执行操作、产生真实结果

### Agent 的核心循环

所有 Agent，不管多复杂，底层都是同一个循环：

```
         ┌──────────────────┐
         │    感知 Perceive  │   ← 读取信息（用户输入、工具返回、环境变化）
         └────────┬─────────┘
                  ↓
         ┌──────────────────┐
         │    决策 Reason    │   ← LLM 思考：理解目标、制定计划、选择工具
         └────────┬─────────┘
                  ↓
         ┌──────────────────┐
         │    行动 Act       │   ← 调用工具、执行操作、改变环境
         └────────┬─────────┘
                  │
                  ↓
            完成了吗？
           ╱         ╲
         否            是
          ↓             ↓
       回到感知       返回结果
```

**感知 → 决策 → 行动 → 感知 → 决策 → 行动 → …… → 完成。**

这个循环和什么很像？——**人类做事的方式。** 你接到一个任务，先了解情况（感知），想一想怎么做（决策），然后动手做（行动），做完看看效果（感知），不满意就调整（决策），再来一遍（行动）。

Agent 就是把这个过程自动化了。

### 和传统软件的本质区别

```
传统软件：  if 条件A → 执行操作1
           if 条件B → 执行操作2
           else → 报错

AI Agent：  感知当前状态 → LLM 自主判断该做什么 → 执行 → 根据结果动态调整
```

打个比方：
- **传统软件是铁轨火车** 🚂 —— 只能沿着预设的轨道走，遇到没铺轨道的地方就停
- **AI Agent 是自动驾驶汽车** 🚗 —— 能根据路况自主判断方向，遇到新情况也能应对

## 02｜Agent 的四大核心能力

一个真正的 Agent 需要具备四种能力：

### 🧠 自主性（Autonomy）

**类比**：一个优秀的助理，你只说"帮我准备明天的会议"，他就自己去查日程、订会议室、发邀请邮件、准备材料，不需要你每一步都指挥。

**技术实现**：LLM 的推理能力让 Agent 能理解高层目标（"准备会议"），自动拆解为具体步骤（查日程→订会议室→发邮请→准备材料），并逐步执行。

```
用户: "帮我准备明天的周会"

Agent 自主拆解:
  1. 查询明天的日程 → 发现 10:00 有空
  2. 预订会议室 B302
  3. 给团队成员发送邀请
  4. 整理上周的项目进展作为议程
  5. 生成会议议程文档
```

### 🔧 工具使用（Tool Use）

**类比**：厨师做菜不是用手撕食材，而是用刀切、用锅炒、用烤箱烤——**工具让能力边界无限扩展**。

**技术实现**：Agent 通过调用外部工具（API、数据库、浏览器、代码解释器等）来完成 LLM 本身做不到的事情。

```
LLM 本身不能做的事          Agent 通过 Tool 可以做
─────────────────          ─────────────────────
❌ 查实时天气                ✅ 调用天气 API
❌ 读写文件                  ✅ 调用文件系统
❌ 执行代码                  ✅ 调用代码解释器
❌ 搜索网络                  ✅ 调用搜索引擎
❌ 发送邮件                  ✅ 调用邮件 API
❌ 操作数据库                ✅ 调用 SQL 执行器
```

> 💡 **深入阅读**：Tool Use 是 Agent 最核心的底层机制，详见 [Agent 底层全是 Tool Use](/ai-agents/agent-fundamentals/agent-is-tool-use)

### 📝 记忆（Memory）

**类比**：一个没有记忆的员工，每天上班都不记得昨天做了什么，你需要重新交代一遍所有背景。一个有记忆的员工，知道项目进度、你的偏好、历史决策，沟通效率完全不同。

**两种记忆**：

| 类型 | 说明 | 实现方式 |
|------|------|---------|
| **短期记忆** | 当前对话的上下文 | 对话历史直接放进 prompt |
| **长期记忆** | 跨对话的持久信息 | 向量数据库存储 + 检索 |

```
短期记忆：
  用户: "我喜欢简洁的代码风格"
  Agent: (记住了，本次对话都会遵循)

长期记忆：
  上周对话: "我的项目用 React + TypeScript"
  今天对话: Agent 自动用 React + TS 写代码（不需要你重新说）
```

### 🗺️ 推理与规划（Reasoning & Planning）

**类比**：让你"从北京去拉萨"，你不会直接起跑。你会先想：坐飞机还是火车？需要准备什么？路线怎么规划？——**先想清楚再行动**。

**技术实现**：LLM 把复杂任务拆解为步骤序列，然后逐步执行。遇到问题还能动态调整计划。

```
目标: "用 Python 分析销售数据并生成可视化报表"

Agent 的规划:
  Step 1: 读取 sales.csv 文件          ← 感知数据
  Step 2: 理解数据结构和字段含义        ← 推理分析
  Step 3: 用 Pandas 清洗数据            ← 行动
  Step 4: 计算关键指标（增长率、占比）   ← 行动
  Step 5: 用 Matplotlib 生成图表        ← 行动
  Step 6: 整合为 HTML 报表              ← 行动
  Step 7: 如果报表有问题 → 回到 Step 4   ← 反思调整
```

## 03｜Agent 的五个发展阶段

AI Agent 的发展可以分为五个阶段，每个阶段能力逐级递进：

```
L1 对话型 → L2 工具型 → L3 任务型 → L4 协作型 → L5 自进化型
  能聊天     能调工具     能做任务    能团队协作    能自我进化
```

### L1 对话型 —— "能聊天"

```
你: 北京天气怎么样？
AI: 我无法获取实时天气，但北京3月一般......
```

只能基于训练数据聊天，不能获取实时信息，不能执行操作。

**代表产品**：早期 ChatGPT、文心一言基础版

### L2 工具型 —— "能调工具"

```
你: 北京天气怎么样？
AI: [调用天气API] 北京今天晴，15°C，微风。
```

能调用外部工具获取信息或执行操作，但每次只能完成**单步任务**。

**代表产品**：ChatGPT with Plugins、GPT-4 Function Calling

### L3 任务型 —— "能做复杂任务"

```
你: 帮我分析这份 CSV 数据，找出销售额下降的原因，生成报告。
AI: [读取文件 → 分析数据 → 发现异常 → 生成图表 → 写报告]
```

能自主拆解复杂任务为多个步骤，按顺序调用多个工具，遇到错误能自动修复。

**代表产品**：Claude with Tools、Cursor Agent、Devin

### L4 协作型 —— "能团队合作"

```
你: 帮我做一个完整的产品调研报告。

研究 Agent → 搜索市场数据
分析 Agent → 处理数据、做竞品分析
写作 Agent → 撰写报告
审核 Agent → 检查质量、提出修改
```

多个专业化 Agent 分工协作，像一个团队一样完成复杂项目。

**代表产品**：AutoGen、CrewAI、ChatDev

### L5 自进化型 —— "能自我进化"（未来）

```
Agent 发现自己在数据分析任务上经常出错
→ 自动分析失败案例
→ 生成新的改进策略
→ 更新自己的知识库和工具集
→ 下次表现更好
```

能从经验中学习，自我优化策略和能力。目前仍处于研究阶段。

**代表研究**：Voyager（Minecraft Agent）、ADAS

### 当前产品处在什么阶段？

| 产品 | 阶段 | 核心能力 |
|------|------|---------|
| ChatGPT 基础版 | L1 | 对话 |
| ChatGPT + Plugins | L2 | 单步工具调用 |
| Claude 3.5 Sonnet | L2-L3 | 多步工具调用 + 复杂推理 |
| Cursor Agent | L3 | 自主编码、调试、修复 |
| Devin | L3 | 全栈开发任务 |
| AutoGen | L4 | 多 Agent 对话协作 |
| CrewAI | L4 | 多 Agent 角色分工 |
| Voyager | L5 探索 | 自主探索学习（Minecraft） |

## 04｜现在都有哪些 Agent？

### 按应用领域分类

#### 💻 编程类 Agent

| 产品 | 能力 | 阶段 |
|------|------|------|
| **Cursor** | AI 驱动的代码编辑器，能理解整个项目、自主编写/修改代码 | L3 |
| **GitHub Copilot** | 代码补全 + 对话编程助手 | L2 |
| **Devin** | 全自主软件工程师，能独立完成开发任务 | L3 |
| **Windsurf** | AI 编程助手，支持多文件协作编辑 | L3 |
| **Bolt.new** | 自然语言直接生成完整 Web 应用 | L3 |

#### 📊 办公类 Agent

| 产品 | 能力 | 阶段 |
|------|------|------|
| **Microsoft Copilot** | Office 全家桶 AI 助手（Word/Excel/PPT/Outlook） | L2-L3 |
| **Notion AI** | 文档写作、知识管理、任务规划 | L2 |
| **Perplexity** | AI 搜索引擎，自动搜索+整合+引用 | L2-L3 |

#### 🎨 创作类 Agent

| 产品 | 能力 | 阶段 |
|------|------|------|
| **Midjourney** | 文本生成高质量图像 | L2 |
| **Runway** | AI 视频生成和编辑 | L2 |
| **Suno** | AI 音乐创作 | L2 |

#### 🤖 通用 Agent 平台

| 平台 | 定位 | 特点 |
|------|------|------|
| **Dify** | 无代码 Agent 搭建平台 | 可视化流程编排 |
| **Coze（扣子）** | 字节旗下 Agent 平台 | 插件丰富、中文生态好 |
| **AutoGen** | 微软开源多 Agent 框架 | 多 Agent 对话协作 |
| **CrewAI** | 开源多 Agent 框架 | 角色化分工协作 |
| **LangGraph** | LangChain 的 Agent 编排框架 | 状态机 + 循环控制 |

## 💡 总结

| 概念 | 一句话理解 |
|------|----------|
| **AI Agent** | 能自主感知、决策、行动来完成目标的 AI 系统 |
| **vs 普通 AI** | 普通 AI 是顾问（给建议），Agent 是员工（干活） |
| **核心循环** | 感知 → 决策 → 行动 → 感知 → …… → 完成 |
| **四大能力** | 自主性、工具使用、记忆、推理规划 |
| **发展阶段** | L1对话 → L2工具 → L3任务 → L4协作 → L5自进化 |
| **当前水平** | 主流产品处于 L2-L3，L4 初步可用，L5 仍在研究 |
