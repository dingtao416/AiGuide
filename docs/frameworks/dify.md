# Dify - AI 工作流平台

Dify 是一个强大的开源 AI 应用构建平台，让您无需深度编程即可创建智能应用。想象一下，像搭积木一样简单地组合 AI 能力，就能打造出专属的智能助手、知识问答系统或者复杂的业务流程自动化工具。

> 💡 **核心理念**：将复杂的 AI 技术简化为可视化的拖拽操作，让每个人都能成为 AI 应用的创造者。

## 🎯 核心特点

### 🎨 可视化编排
- **拖拽式设计**：无需编写代码，通过拖拽组件快速构建 AI 工作流
- **实时预览**：所见即所得，实时查看应用效果
- **模板丰富**：提供多种场景模板，一键开始

### 🚀 开箱即用
- **RAG 能力**：内置检索增强生成，轻松构建知识问答系统
- **Agent 智能体**：支持多步推理和工具调用的智能代理
- **多种应用类型**：聊天机器人、文本生成、工作流等

### 🤖 多模型支持
- **主流 LLM**：OpenAI、Claude、文心一言、通义千问等
- **本地模型**：支持开源模型私有化部署
- **模型切换**：一键切换不同模型，对比效果

### 🔐 开源安全
- **完全开源**：MIT 协议，代码透明可审计
- **私有化部署**：数据不出本地，保障隐私安全
- **企业级**：支持单点登录、权限管理等企业功能

## 🚀 部署指南

### 部署方式选择

Dify 提供两种主要的部署方式，您可以根据实际需求选择：

#### 🐳 Docker Compose 部署（推荐）
**适合人群**：希望快速上手、注重稳定性的用户

**特点**：
- ✅ 容器化部署，所有组件预打包
- ✅ 一键启动，部署简单
- ✅ 环境隔离，升级方便
- ✅ 生产环境友好

#### 💻 本地源码部署
**适合人群**：需要二次开发、深度定制的开发者

**特点**：
- ✅ 代码调试方便
- ✅ 更细粒度的控制
- ⚠️ 需手动配置环境
- ⚠️ 维护成本较高

### 环境要求

在开始部署之前，请确保您的环境满足以下要求：

| 项目 | 要求 | 备注 |
|------|------|------|
| **操作系统** | Linux / macOS / Windows | 推荐 Ubuntu 20.04+ |
| **Docker** | Docker Engine + Docker Compose | 必须安装 |
| **CPU** | 2 核心以上 | 生产环境建议 4 核心+ |
| **内存** | 4GB 以上 | 生产环境建议 8GB+ |
| **存储** | 20GB 可用空间 | 用于存储数据和日志 |

### 快速部署步骤

#### 第一步：获取源码
```bash
git clone https://github.com/langgenius/dify.git
cd dify
```

#### 第二步：配置环境变量
```bash
# 复制环境变量模板
cp .env.example .env

# 编辑配置文件
vim .env
```

**核心配置说明**：
```bash
# 控制台访问地址（管理后台）
CONSOLE_API_URL=https://dify.your-domain.com
CONSOLE_WEB_URL=https://dify.your-domain.com

# 应用服务地址（用户访问）
SERVICE_API_URL=https://dify.your-domain.com
APP_API_URL=https://dify.your-domain.com
APP_WEB_URL=https://dify.your-domain.com

# 文件服务地址
FILES_URL=https://dify.your-domain.com
```

> 💡 **提示**：如果是本地测试，可以将域名替换为 `http://localhost`

#### 第三步：启动服务
```bash
# 后台启动所有服务
sudo docker compose up -d

# 查看运行状态
sudo docker compose ps
```

#### 第四步：验证部署
- 访问 `http://localhost` 进入控制台
- 注册管理员账号
- 开始创建您的第一个 AI 应用

## 🛠️ 应用场景

### 1. 智能客服系统
构建基于企业知识库的智能客服，自动回答常见问题，提升服务效率。

### 2. 文档问答助手
上传企业文档，创建专业的文档问答系统，快速检索和获取信息。

### 3. 内容生成工具
设计文案生成、报告撰写等内容创作工具，提升工作效率。

### 4. 业务流程自动化
构建复杂的业务流程，集成多个 API 和服务，实现端到端自动化。
