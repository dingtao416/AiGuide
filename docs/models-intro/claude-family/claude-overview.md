# Claude 系列模型全览

> Claude 是什么、有哪些模型、该怎么选 —— 写给每一个对 AI 好奇的人

## Claude 是什么？

Claude 是 Anthropic 公司开发的 AI 助手。如果 GPT 是 OpenAI 的"孩子"，那 Claude 就是一群从 OpenAI 出走的科学家创造的"另一个天才"。

Anthropic 的核心理念是 **Constitutional AI（宪法式 AI）**——让 AI 遵循一套明确的"行为准则"，确保回答安全、诚实、无害。简单说：**他们不只追求 AI 有多聪明，更在意 AI 有多靠谱。**

Claude 特别擅长三件事：

- **长文本处理**：一次性"读"完几十万字的文档并理解它（上下文窗口 100 万 token，相当于三本《三体》的长度）
- **深度推理**：擅长复杂逻辑分析、学术研究、代码架构
- **流畅写作**：文笔自然细腻，中文表达尤其出色

## Claude 进化简史

```
2023 ── Claude 1 / Claude 2 ── 最初的版本，首次开放 API
2024 ── Claude 3 系列 ── Opus / Sonnet / Haiku 三档确立，能力大幅提升
2025 ── Claude 4 系列 ── 推理能力飞跃，Agent 能力成熟
2026 ── Claude 4.7 ── Opus 4.7 / Sonnet 4.6 / Haiku 4.5 当前最新阵容
```

### 关键里程碑

**Claude 3 系列（2024年3月）** — Anthropic 首次明确划分三个层级：Opus（最强）、Sonnet（平衡）、Haiku（最快）。Claude 3 Opus 在当时多项基准测试中超越 GPT-4。

**Claude 4 系列（2025年）** — 推理能力大幅跃升，引入了 Extended Thinking（扩展思考）功能，让模型在回答前可以进行深度推理。Agent 能力成熟，能自主操作电脑、浏览网页。

**Claude Opus 4.7 / Sonnet 4.6 / Haiku 4.5（2026年）** — 当前最新阵容。Opus 4.7 是最强旗舰，在复杂编程、Agent 任务上实现了显著提升。Sonnet 4.6 是速度与智能的最佳平衡。Haiku 4.5 在极快速度下保持了接近前沿的能力水平。

## 当前三模型定位

_截至 2026 年 5 月_

| 模型           | 定位     | 一句话总结           | 适合做什么                                             |
| -------------- | -------- | -------------------- | ------------------------------------------------------ |
| **Opus 4.7**   | 旗舰     | 最聪明的"专家顾问"   | 高难度编程、学术论文、复杂合同分析、需要深度思考的任务 |
| **Sonnet 4.6** | 平衡之选 | 什么都行的"全能选手" | 日常对话、内容创作、一般编程、文档处理、学习辅助       |
| **Haiku 4.5**  | 快速响应 | 闪电般的"快手助手"   | 简单问答、快速查询、大批量任务处理、轻量交互           |

### Extended Thinking（扩展思考）

Opus 4.7 和 Sonnet 4.6 支持 Extended Thinking —— 遇到复杂问题时，模型会像人类一样"多想一想"，用更多的计算时间确保答案靠谱。这在数学、编程、逻辑推理中尤其有用。

> 就像考试时：Haiku 看一眼就写答案（快但可能错），Opus 会仔细打草稿再作答（慢但更准）。

## 我应该用哪个？

| 你的需求                     | 推荐           | 说明                           |
| ---------------------------- | -------------- | ------------------------------ |
| 日常聊天、写作、学习         | **Sonnet 4.6** | 性价比最高，日常使用完全够     |
| 攻克难题：复杂编程、深度分析 | **Opus 4.7**   | 最强推理，多花时间换更准的结果 |
| 简单问答、快速查询           | **Haiku 4.5**  | 秒回，体验流畅                 |
| 不确定                       | **Sonnet 4.6** | 先从这个开始，够用就不用换     |
