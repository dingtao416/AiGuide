# Claude 使用指南

> Claude.ai 怎么用、有什么特色、和 ChatGPT 有什么不同

## Claude.ai 上手

### 注册就能用

访问 [claude.ai](https://claude.ai)，用 Google 账号或邮箱注册。免费版就能使用 Sonnet 模型，日常需求完全够。

### 界面一览

和大多数 AI 聊天工具类似，界面非常简洁：

- **中间** — 对话框，输入你的问题
- **左下角** — 模型选择器（Sonnet / Opus / Haiku）
- **右下角** — 上传文件按钮（支持 PDF、图片、Word、Excel、代码文件等）
- **左侧** — 对话历史、Projects（项目空间）

### 上传文件让 Claude 分析

Claude 支持上传各种格式的文件。点击输入框旁边的回形针图标，选择文件即可：

- **PDF** — 论文、合同、报告，Claude 能通读整篇并回答你的问题
- **图片** — 图表、白板笔记、菜单照片，Claude 能"看懂"
- **Excel / CSV** — 数据表格，Claude 能分析并给出洞察
- **代码文件** — 支持几乎所有编程语言

## Claude 的特色功能

### 1. 超长上下文：一次读完一整本书

Claude 最突出的能力是**超长上下文**。Opus 4.7 和 Sonnet 4.6 一次能处理 100 万 token —— 相当于三本《三体》的长度。

这意味着你可以：

- 上传一份 200 页的 PDF 合同，让 Claude 逐条分析风险点
- 扔给它一整本书，让它写读书笔记
- 把整个项目的代码文件全给它，让它理解架构

**这是 Claude 相比其他 AI 最大的差异化优势。**

### 2. Artifacts：对话中"长"出来的交互窗口

当 Claude 生成代码、文档、网页、图表等可以独立展示的内容时，它会自动创建一个 **Artifact** —— 一个在对话旁边弹出的可交互窗口，你可以：

- **实时预览**：生成的网页、SVG 图表直接渲染出来
- **一键复制**：复制代码或文本内容
- **下载保存**：把生成的 HTML/代码保存到本地

> 比如你对 Claude 说"帮我画一个公司组织架构图"，它不光给你文字描述，还会直接生成一个可交互的图表。

### 3. Projects：定制专属 Claude

Projects 让你创建一个独立的工作空间，在里面可以：

- 上传知识库文件（公司文档、项目规范、学习资料）
- 设定自定义指令（"用中文回答""以产品经理视角分析"）
- 所有在这个 Project 中的对话都会参考这些上下文

**相当于你给 Claude 做了一个"岗前培训"**，它在这个项目里就是你的专属顾问。

### 4. 语音对话

手机 App（iOS / Android）支持语音对话模式。适合开车、走路时提问，或者练习口语对话。

## 和 ChatGPT 比有什么不同？

这是大家问最多的问题。简单说：**不是谁更好，而是谁更适合当下这个任务。**

| 维度           | Claude                      | ChatGPT                     |
| -------------- | --------------------------- | --------------------------- |
| **长文本**     | 100 万 token，碾压级优势    | 较短的上下文窗口            |
| **文笔**       | 自然细腻，中文尤其好        | 实用但偏"模板化"            |
| **深度分析**   | 擅长长文档深度解析          | 综合能力强                  |
| **画图**       | 不支持直接生成图像          | GPT Image 1，独家优势       |
| **编程 Agent** | Claude Code，原生产品       | 第三方工具为主              |
| **生态集成**   | 相对精简                    | 插件、商店、搜索集成更丰富  |
| **安全理念**   | Constitutional AI，保守克制 | 功能驱动，更激进            |
| **价格**       | Pro $20/月，含 Claude Code  | Plus $20/月，不含编程 Agent |

### 实际建议

**两个都用。** Claude 适合长文档分析、深度写作、代码项目。ChatGPT 适合画图、快速问答、多元创意。就像你厨房里有炒锅也有蒸锅，看做什么菜用什么工具。

日常使用中，很多用户的感觉是：

- 需要"认真做事"时 → Claude（长文档、严肃分析、代码）
- 需要"轻松探索"时 → ChatGPT（画图、创意、随便聊聊）

## 日常场景举例

### 读书学习

> 上传一本 PDF 电子书："这是我正在读的《人类简史》，帮我总结第三章的核心观点，指出作者使用了哪些论证方法。"

> "我在学机器学习，卡在了'梯度下降'这个概念上。用最简单的比喻帮我理解，假设我只有初中数学基础。"

### 写作润色

> "下面是我写的产品介绍，帮我润色，让语言更有销售力，但保持真诚不浮夸。"

> "这是我写的英文邮件，帮我检查语法，让表达更地道。不要重写，在原文基础上修改。"

### 代码辅助

> 粘贴一段报错："我的 Python 代码报这个错，帮我分析原因和修复方案。"

> "帮我写一个 SQL 查询：从订单表中找出过去 30 天消费最高的 10 个客户，显示他们的总消费金额和订单数。"

### 合同分析

> 上传一份合同 PDF："帮我检查这份租房合同，标注出对租客不利的条款，用中文解释。"

> 上传一份服务协议："这是我们的 SaaS 服务协议草稿，帮我从客户视角分析有哪些地方可能引起争议。"
