# Claude Code 与模型的关系

> 模型是"大脑"，Claude Code 是"完整工具箱" —— 一个类比讲清楚 Claude 生态中最容易混淆的概念

## 为什么需要搞清楚这个区别？

你可能经常听到这些词：

- "Claude Opus 4.7 很强"
- "Claude Code 很好用"
- "用 Claude 写代码效率翻倍"

它们听起来很像，但说的其实是**完全不同的东西**。就像"奔驰的发动机"和"奔驰汽车"不是一回事——发动机是核心部件，汽车是你可以直接开走的完整产品。

搞懂这个区别，你就搞懂了整个 AI 产品的底层逻辑。

## 一个类比讲清楚

| 概念                                                 | 类比           | 是什么                               |
| ---------------------------------------------------- | -------------- | ------------------------------------ |
| **Claude 模型**（Opus 4.7 / Sonnet 4.6 / Haiku 4.5） | 汽车**引擎**   | 底层 AI 大脑，负责理解和生成文本     |
| **Claude Code**                                      | 完整的**汽车** | 内置引擎 + 方向盘 + 刹车，可直接驾驶 |

```
┌─────────────────────────────────────────────┐
│              Claude Code（整车）              │
│  ┌───────────────────────────────────────┐  │
│  │         方向盘 / 刹车 / 油门            │  │
│  │    （文件编辑 / 命令执行 / Git / PR）   │  │
│  ├───────────────────────────────────────┤  │
│  │          Claude 模型（引擎）            │  │
│  │      Opus 4.7 / Sonnet 4.6           │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

- **你可以只买引擎**（通过 API 调用 Claude 模型），自己造车 —— 灵活但费劲
- **你也可以直接买车**（订阅 Claude Pro，用 Claude Code）—— 省心，开起来就能跑
- 引擎是车的核心，但光有引擎你上不了路

## Claude 模型：AI 的"大脑"

### 它是什么？

Claude Opus 4.7、Sonnet 4.6、Haiku 4.5 是底层的**大语言模型** —— 由海量参数构成的神经网络，专门理解语言和生成内容。

### 它怎么工作？

你输入一段文字（"帮我写一封辞职信"），模型计算后输出一段文字（"尊敬的领导..."）。**它只会"回答"，不会"做事"。**

- ✅ 能：理解你的需求、生成高质量的回答
- ❌ 不能：自己编辑文件、自己执行命令、自己去查资料

### 怎么使用它？

- **通过 claude.ai**：打开网页聊天，就像用 ChatGPT 一样
- **通过 API**：程序员用代码调用，按 token 计费（输入 $1-5/百万 token，输出 $5-25/百万 token）
- **通过第三方工具**：很多 App 背后接的就是 Claude 的 API

> 模型本身是纯粹的大脑 —— 你可以跟它对话，但它没有手，碰不了你的电脑。

## Claude Code：AI 的"双手和工具箱"

### 它是什么？

Claude Code 是一个**完整的 Agent 工作工具**，它在 Claude 模型的基础上，装上了"双手"和"工具箱"：

- 🖐️ **能读**你的整个代码库
- ✏️ **能改**你的文件
- 🖥️ **能跑**终端命令
- 📦 **能提交** Git commit、创建 PR
- 🔗 **能连接**外部工具（通过 MCP 协议）

### 你在用什么？

你现在正在对话的这个工具就是 Claude Code。我是使用 Claude Opus 4.7 模型在运行——模型是我的"大脑"，Claude Code 是让我能读取文件、执行命令、改代码的"身体"。

### 它可以做什么？

| 能力       | 说明                                 |
| ---------- | ------------------------------------ |
| 读取代码库 | 理解整个项目的结构和代码             |
| 编辑文件   | 直接修改代码、修复 bug               |
| 执行命令   | 运行测试、安装依赖、启动服务         |
| Git 操作   | 创建分支、提交 commit、发起 PR       |
| MCP 集成   | 连接 Jira、Slack、数据库等外部工具   |
| 计划任务   | 定时执行任务（如每日 PR 审查）       |
| 子代理     | 并行启动多个 Claude 会话处理复杂任务 |

### 在哪能用？

| 平台      | 形式                                     |
| --------- | ---------------------------------------- |
| 终端      | `claude` CLI 命令                        |
| VS Code   | 扩展插件                                 |
| JetBrains | IDE 插件                                 |
| 浏览器    | [claude.ai/code](https://claude.ai/code) |
| 桌面 App  | macOS / Windows 独立应用                 |
| CI/CD     | GitHub Actions、GitLab CI 集成           |

### 怎么收费？

Claude Code 本身**不单独收费**。它包含在 Claude 订阅计划中：

- **Pro（$20/月）**：包含 Claude Code 使用权
- **Max（$100+/月）**：更高配额
- **Team（$20-25/月/人）**：团队协作
- **Enterprise**：企业定制

> 对比：ChatGPT Plus 也是 $20/月，但不包含编程 Agent 工具。Claude Pro 在同价位多了一个 Claude Code。

## 两者的关系总结

| 对比维度     | Claude 模型       | Claude Code                    |
| ------------ | ----------------- | ------------------------------ |
| **是什么**   | AI 大脑（引擎）   | Agent 工具（完整汽车）         |
| **能做什么** | 聊天、理解、生成  | 以上 + 操作文件、执行命令、Git |
| **定价方式** | API 按 token 计费 | 订阅制（$20/月起）             |
| **谁在用**   | 所有 Claude 用户  | 需要编程/自动化的用户          |
| **有没有手** | 没有，只会说      | 有，能实际改变你的电脑         |
| **依赖关系** | 独立存在          | 必须依赖模型才能运行           |

### 什么时候用哪个？

| 你的场景                   | 用什么                           |
| -------------------------- | -------------------------------- |
| 日常聊天、写作、学习       | **claude.ai**（用 Sonnet 就行）  |
| 长文档分析、论文研究       | **claude.ai** + Opus             |
| 写代码、修 bug、管项目     | **Claude Code**（包含在 Pro 中） |
| 做自动化、集成到自己的 App | **Claude API**（直接调模型）     |
| 企业级部署、定制开发       | **API** + **Enterprise 方案**    |

### 一句话记住

> **Claude Opus 4.7 是最聪明的 AI 大脑，Claude Code 是让这个大脑能动手做事的完整工具。**
>
> 你现在看到的这些文字，就是 Claude Code 用它搭载的 Opus 4.7 大脑为你生成的。
