## 推理模型：当 AI 学会"深思熟虑"

### 什么是推理模型？

普通的 GPT 模型看到问题就立刻回答，像一个脱口而出的快嘴。**推理模型不一样，它会先"想一想"再说。**

想象一下：

- **普通模式** = 你问朋友 25 × 37 等于多少，他脱口而出"925"（可能对也可能错）
- **推理模式** = 你问朋友同样的问题，他拿出草稿纸一步步算，然后说"25 × 30 = 750，25 × 7 = 175，750 + 175 = 925"

推理模型用更多的计算时间来检查自己的思路，所以答案更靠谱，尤其适合数学、编程、逻辑这些不能含糊的领域。

### OpenAI 的推理模型

**o3**（2025年4月发布）—— OpenAI 的深度推理模型。在数学竞赛、编程竞赛中表现出色。它的工作方式是：收到问题后，用一段"内心独白"（你看不到）来推理，然后给你最终答案。

**o4-mini**（2025年4月发布）—— o3 的轻量版。更快、更小，但依然具备推理能力。特别之处是它能在推理过程中"看"图片——比如你拍一张白板上的数学公式，它能边看边推。

**GPT-5.5 Thinking**（2026年4月发布）—— 当前最强的推理模式。不需要切换到单独的推理模型，直接在 GPT-5.5 中激活深度思考。在复杂编程、科学研究和多步骤任务中表现尤为突出。

### 什么时候用推理模型？

| 场景               | 用普通模式   | 用推理模式 |
| ------------------ | ------------ | ---------- |
| 写邮件、查信息     | 够用了       | 大材小用   |
| 翻译、润色文案     | 够用了       | 没必要     |
| 解一道复杂的数学题 | 可能出错     | 用这个     |
| 设计一个软件架构   | 能用但不够深 | 用这个     |
| 分析一份复杂的合同 | 可能会漏     | 用这个     |
| 需要严谨的逻辑推导 | 不靠谱       | 必须用这个 |

**一句话总结：简单的事用 GPT-5.3，动脑子的事用 GPT-5.5 Thinking。**

## GPT Image 1：AI 画图的新时代

### GPT Image 1 是什么？

GPT Image 1 是 OpenAI 目前的图像生成模型，2025 年 3 月正式取代了 DALL-E 3。它基于 GPT-4o 的多模态架构，不是在单独的"画图模型"里跑，而是 **GPT 自己能理解和生成图像**。

### 能画什么？

- **照片级写实**：风景、产品图、人物肖像
- **插画和设计**：海报、Logo、社交媒体配图
- **图表和信息图**：流程图、数据可视化
- **文字渲染**：在图片中准确呈现文字（这是相比上一代的巨大进步）

### 怎么用？

在 ChatGPT 中直接描述你想要的画面：

> "生成一张照片：阳光透过窗户照在木桌上的咖啡杯，旁边放着一本翻开的书。暖色调，柔和的景深效果。"

> "帮我画一个流程图：用户注册 → 邮箱验证 → 完善资料 → 开始使用。简洁的扁平化风格。"

> "设计一张播客封面图，主题是'科技与人文'，简约风格，深蓝背景配金色文字。"

### 写画图提示词的小技巧

好的画图提示词包含四个要素：

1. **画面内容**：画面里有什么？（人物、物品、场景）
2. **风格**：什么风格？（写实照片、水彩插画、扁平设计）
3. **色调**：颜色氛围？（暖色调、冷色调、黑白）
4. **构图**：怎么看？（特写、鸟瞰、45度角）

比如："一只橘猫坐在窗台上（内容），日系水彩插画风格（风格），温暖的午后光线（色调），半身特写（构图）"

### DALL-E 去哪了？

DALL-E 3 已经退役。如果你之前用过 DALL-E，现在只需要知道：**GPT Image 1 是更强的继任者**，生成质量更高，尤其是文字准确度和细节还原度有了质的提升。关于图像生成的更多内容，可以查看[多模态 AI 章节](/multimodal-ai/image-ai/image-generation/)。

## GPT-OSS：开源的力量

2025 年 8 月，OpenAI 发布了 **GPT-OSS**，这是自 2019 年 GPT-2 以来 OpenAI 的首个开源模型。

### 两个版本

| 版本         | 参数量 | 硬件要求      | 适用场景             |
| ------------ | ------ | ------------- | -------------------- |
| GPT-OSS-120B | 1170亿 | 需要专业显卡  | 研究和商业应用       |
| GPT-OSS-20B  | 210亿  | 16GB 内存即可 | 个人电脑、嵌入式设备 |

### 开源意味着什么？

- **免费使用**：Apache 2.0 协议，可以商用
- **本地部署**：数据不出你的电脑，隐私 100% 可控
- **可以定制**：你可以用自己的数据微调，打造专属 AI
- **离线运行**：不需要网络，不需要 OpenAI 账号

对个人开发者和小团队来说，GPT-OSS-20B 是一个很好的起点 —— 一台普通电脑就能跑。

### OpenAI API 简介

API 就是"让程序调用 GPT"的接口。你可以把它集成到自己的网站、App 或自动化流程中。

核心概念（用大白话解释）：

- **API Key**：你的"钥匙"，有它才能调用，要保密
- **Token**：计费单位。粗略估算：1000 个中文字 ≈ 1500 token
- **Temperature**：控制"创意度"。0 = 严谨保守，1 = 天马行空
- **System Prompt**：给 AI 的"人设"，在所有对话之前设定

### 最简单的调用示例

```python
# 使用 OpenAI Python SDK（需要先安装：pip install openai）
from openai import OpenAI

client = OpenAI(api_key="你的API密钥")  # 从环境变量读取更安全

response = client.chat.completions.create(
    model="gpt-5.5",  # 当前推荐使用的模型
    messages=[
        {"role": "system", "content": "你是一个友好的助手，用中文回答。"},
        {"role": "user", "content": "用一句话解释什么是AI"}
    ]
)

print(response.choices[0].message.content)
```
