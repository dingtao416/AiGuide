# Nano Banana 与 Veo：Gemini 的多模态生成能力

> 画图、做视频 —— Gemini 不只是会聊天。一文搞懂 Nano Banana 和 Veo 是什么、能做什么、和 Sora 比怎么样

## Nano Banana：Gemini 的原生图像引擎

### 它是什么？

**Nano Banana 是 Google 给 Gemini 原生图像生成能力起的内部代号。** 它不是单独的 App 或独立模型，而是内建在 Gemini 模型中的图像生成与编辑能力。

这和其他 AI 画图工具有本质区别：

| 对比         | Nano Banana               | DALL-E / Midjourney 等   |
| ------------ | ------------------------- | ------------------------ |
| **运行方式** | 内嵌在 Gemini 聊天中      | 独立模型/独立工具        |
| **交互方式** | 对话式，你边说它边改      | 单次输入提示词，单次输出 |
| **理解能力** | Gemini 的完整推理能力加持 | 主要靠提示词引导         |
| **编辑方式** | 多轮对话迭代修改          | 每次重新生成             |

> 用 Nano Banana 就像和一个懂设计的 AI 设计师聊天 —— "帮我把背景换成蓝色""把这个人去掉""换个更活泼的风格"——它能理解你的意思并直接修改，不必从头生成。

### Nano Banana 的三个版本

| 版本                | 搭载模型               | 定位             | 最高分辨率 |
| ------------------- | ---------------------- | ---------------- | ---------- |
| **Nano Banana**     | Gemini 2.5 Flash Image | 基础版，快速生成 | 1024px     |
| **Nano Banana 2**   | Gemini 3.1 Flash Image | 高吞吐版，速度快 | 2K         |
| **Nano Banana Pro** | Gemini 3 Pro Image     | 专业版，推理增强 | 4K         |

### 能做什么？

**文生图** — 最基础的能力，根据文字描述生成图像：

> "生成一张照片：东京涉谷十字路口，雨后黄昏，霓虹灯反射在潮湿的地面上，电影感构图"

**图片编辑** — 上传一张图，让 AI 修改它：

- "把这张照片里的路人去掉"
- "把天空换成夕阳"
- "给这个人换一件红色的外套"

**多轮迭代编辑** — 这是 Nano Banana 的核心优势：

> 你："帮我画一只猫"
> AI：[生成一只猫]
> 你："加上一顶帽子"
> AI：[给猫加上帽子]
> 你："帽子换成蓝色，背景改成花园"
> AI：[蓝色帽子的猫在花园里]

每次修改都在之前的基础上进行，不会丢失之前的细节。这比"每次重新描述一遍"要高效得多。

**风格迁移** — 上传一张图作为风格参考，"帮我把这张风景照片画成宫崎骏动画的风格"

**角色一致性** — 生成多张包含同一个角色的图片，角色在不同场景中保持一致。这对漫画、绘本创作非常实用。

**文字渲染** — 在图像中精准呈现文字（比如海报标题、Logo），这是上一代 AI 画图工具的软肋，Nano Banana 有了明显改善。

**搜索接地** — Nano Banana 2 和 Pro 可以接入 Google 搜索，生成图像时引用实时数据。比如"画一张 2026 年最畅销车型的对比图"，它能查到最新数据再画。

### 安全性

所有 Nano Banana 生成的图片都会嵌入 **SynthID 水印**（肉眼不可见但机器可识别），用于标识 AI 生成内容。Google 内置了内容安全过滤，拒绝生成敏感或违规内容。

## Veo：Google 的视频生成引擎

### Veo 是什么？

Veo 是 Google DeepMind 开发的视频生成模型，即 **Google 对标 OpenAI Sora 的产品**。最新版本是 **Veo 3.1**。

### Veo 3.1 的核心能力

**文生视频** — 输入一段描述，输出一段视频：

> "一只金毛犬在海滩上追逐浪花，夕阳西下，慢动作，电影质感"

**图生视频** — 上传一张图片，让它"动起来"：

> 上传一张风景照："镜头缓缓推进，画面中的云开始飘动，树叶随风摇曳"

**原生音频生成** — Veo 3.1 能同时生成视频画面和配套音频（环境音、对白、音乐），不需要后期配音。这是相比上一代的重大升级。

**角色一致性** — 同一个角色会贯穿整个视频，不会出现"换一个镜头脸变了"的情况。

**场景延伸** — 给定一段视频，Veo 能够自然地延长它，保持原有风格和节奏。

**运镜控制** — 你可以指定镜头运动方式：推近、拉远、平移、环绕等，就像有一个虚拟摄影师。

### Veo 输出规格

| 规格   | 说明                |
| ------ | ------------------- |
| 分辨率 | 1080p 标准，最高 4K |
| 时长   | 可定制，按秒计费    |
| 水印   | 全部嵌入 SynthID    |
| 帧率   | 流畅播放            |

### Veo 在哪能用？

- **Gemini** — 直接在聊天中生成视频（逐步开放）
- **Google Vids** — Google 的 AI 视频创作工具
- **Google AI Studio** — 开发者试用
- **Vertex AI** — 企业级 API
- **Google Flow** — 创意工作流平台

### Veo 的价格

| 版本         | 每秒价格      |
| ------------ | ------------- |
| Veo 3.1 标准 | $0.40 - $0.60 |
| Veo 3        | $0.40         |
| Veo Lite     | $0.05 - $0.08 |

## Veo vs Sora：Google 和 OpenAI 的视频生成之战

| 对比维度       | Veo 3.1（Google）            | Sora（OpenAI） |
| -------------- | ---------------------------- | -------------- |
| **视频分辨率** | 最高 4K                      | 最高 1080p     |
| **音频生成**   | 原生音频（环境音+对白+音乐） | 无原生音频     |
| **角色一致性** | 强，跨场景保持一致           | 一般           |
| **运镜控制**   | 支持（推拉摇移）             | 有限           |
| **图片转视频** | 支持                         | 支持           |
| **视频延长**   | 支持场景延伸                 | 支持           |
| **生态整合**   | Google 全家桶                | ChatGPT + API  |
| **水印**       | SynthID                      | C2PA           |
| **可用性**     | Gemini + AI Studio           | ChatGPT + API  |

### 谁更好？

两者定位不同：

- **Veo** 更注重**生产级质量**：4K、原生音频、运镜控制 —— 面向真正的视频创作者
- **Sora** 更注重**创意探索**：生成速度快、交互简单 —— 面向大众用户

目前 Veo 在技术规格上领先（4K + 音频），但 Sora 在易用性和生态上更有优势。两者都在快速迭代，差距随时可能变化。

## 关于 Sora 的说明

**Sora 是 OpenAI 出品的视频生成模型**，不是 Google 的产品。但 Gemini 系列的 Veo 是 Sora 的直接竞争对手。如果你对 Sora 感兴趣，可以关注 OpenAI 和 ChatGPT 的更新。

> 简单记忆：需要视频 → Gemini 用 Veo，ChatGPT 用 Sora。两家都有，看哪个效果好就用哪个。

## Imagen 4 和 Lyria 3

除了 Nano Banana 和 Veo，Google 还有两个独立的专业模型：

### Imagen 4（独立图像生成模型）

和 Nano Banana 不同，Imagen 是一个独立的、专门用于图像生成的模型，通过 Gemini API 调用：

| 版本     | 每张价格 | 适合               |
| -------- | -------- | ------------------ |
| Fast     | $0.02    | 快速生成，大量调用 |
| Standard | $0.04    | 日常使用           |
| Ultra    | $0.06    | 最高质量输出       |

**Nano Banana vs Imagen 怎么选？**

- 需要边聊边改 → Nano Banana（对话式交互）
- 需要批量生成、通过 API 调用 → Imagen 4

### Lyria 3（音乐生成）

Google DeepMind 的音乐生成模型，可以生成各种风格的音乐和音频。与 Veo 3.1 配合使用时，能为视频自动生成匹配的配乐。
