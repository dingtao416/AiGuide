# Gemini 使用指南

> Gemini 怎么用、Google 生态怎么整合、和 ChatGPT/Claude 有什么不同

## Gemini 上手

### 三种使用方式

| 方式                 | 地址                                               | 适合                 |
| -------------------- | -------------------------------------------------- | -------------------- |
| **Gemini 网页**      | [gemini.google.com](https://gemini.google.com)     | 日常聊天、写作、学习 |
| **Google App**       | iOS / Android 中的 Gemini 标签                     | 手机端使用，语音对话 |
| **Google AI Studio** | [aistudio.google.com](https://aistudio.google.com) | 开发者试用，免费额度 |

### 订阅方案

| 方案            | 价格                                  | 内容                                      |
| --------------- | ------------------------------------- | ----------------------------------------- |
| 免费            | $0                                    | Gemini 3.1 Flash，基本功能                |
| Gemini Advanced | $19.99/月（含 Google One AI Premium） | Pro 模型、2TB 存储、Google 全家桶 AI 功能 |

### 上传文件分析

Gemini 支持上传图片、PDF、Word、Excel、代码文件等。特别的是，它还能**直接连接你的 Google Drive**，分析云盘里的文件而不用下载再上传。

## Google 生态整合：Gemini 最独特的能力

这是 Gemini 相比 ChatGPT 和 Claude 最大的差异化优势 —— 它深度嵌入你每天都在用的 Google 工具中。

### Gmail 中的 Gemini

在 Gmail 侧边栏打开 Gemini，直接帮你：

> "帮我总结过去一周所有来自客户邮件中的关键需求"

> "起草一封回复，确认周四下午 3 点的会议时间"

### Google Docs 中的 Gemini

写文档时，Gemini 就在旁边：

> 选中一段文字："帮我把这段改写得更正式/更口语化"

> "根据这份文档内容，生成一页执行摘要"

### Google Maps 中的 Gemini

> "帮我在附近找一家评分高的日料，要能走路到达，顺便规划路线"

> "规划一个周末自驾游路线，沿途要有 3 个适合拍照的景点"

### Google Search 中的 AI 模式

搜索结果顶部会出现 Gemini 生成的 AI 总结，附带来源链接。问复杂问题时尤其有用 —— 它会把多个来源的信息整合成易懂的答案。

### YouTube 视频理解

> 粘贴一个 YouTube 链接："帮我总结这个视频的核心观点，列出时间线"

> "这个教程视频讲了 5 个步骤，帮我整理笔记"

## 特色功能

### Deep Research：AI 帮你写研究报告

给 Gemini 一个研究主题，它会自动在网搜索数十个网页，分析整理后生成一份结构完整的研究报告。适合：

- 市场调研、竞品分析
- 学术文献综述
- 新领域快速入门

> "帮我研究一下 2026 年电动汽车充电桩行业的现状，包括市场规模、主要玩家、技术趋势"

### Gems：创建专属 AI 助手

Gems 是 Gemini 的可定制版本，类似 ChatGPT 的 GPTs。你可以为特定任务创建专属的 AI 助手：

- "写作导师 Gem"：专门润色文章、给出写作建议
- "健身教练 Gem"：记录训练、定制饮食计划
- "代码审查 Gem"：专注代码质量检查

每个 Gem 都可以设定自定义指令，让它记住你的偏好和需求。

### 实时对话（Live）

在手机上打开 Gemini App，进入 Live 模式，就能像打电话一样和 AI 实时对话。Gemini 3.1 Flash Live 支持音频到音频的实时响应，延迟极低。

## 和 ChatGPT、Claude 对比

| 维度         | Gemini                   | ChatGPT           | Claude             |
| ------------ | ------------------------ | ----------------- | ------------------ |
| **生态整合** | Google 全家桶，独一档    | Microsoft 365     | 相对独立           |
| **搜索能力** | Google 搜索原生接地      | 需手动开启搜索    | 需上传文件         |
| **多模态**   | 原生，文本+图+音+视频    | 图+文本强，视频弱 | 图+文本            |
| **长上下文** | 200K+ token              | 较短              | 100 万 token，最强 |
| **画图**     | Nano Banana 原生生成     | GPT Image 1       | 不支持直接生成     |
| **视频生成** | Veo 3.1                  | Sora              | 无                 |
| **免费版**   | 功能较全                 | 功能较全          | 基础               |
| **价格**     | $19.99/月（含 2TB 存储） | $20/月            | $20/月             |

### 选择建议

| 场景             | 推荐                                     |
| ---------------- | ---------------------------------------- |
| 重度 Google 用户 | **Gemini** — 生态整合无人能敌            |
| 需要画图         | **ChatGPT** 或 **Gemini**（Nano Banana） |
| 需要生成视频     | **Gemini**（Veo）或 **ChatGPT**（Sora）  |
| 长文档分析       | **Claude**（100万 token 上下文）         |
| 日常通用         | 三个都试试，选你喜欢的                   |

**不必只选一个。** 日常用 Gemini（生态方便），深度分析用 Claude（长文本强），画图/创意用 ChatGPT（功能全）。三者在免费版上都足够日常使用。
