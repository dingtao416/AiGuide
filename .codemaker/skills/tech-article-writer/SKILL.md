# 专业技术文章撰写工具

专业的技术文章撰写生成工具，能够根据用户提供的主题，智能创造各种类型的技术文章。支持多种写作风格，自动适应文章结构，以及丰富的内容类型。

## 支持的内容类型

### 1. 多样化的文章类型
- **教程指南**：详细的步骤说明和实操指导
- **概念解释**：深入浅出的技术概念说明
- **实战案例**：基于真实项目的应用分析
- **技术对比**：不同解决方案的横向比较
- **趋势分析**：技术发展趋势和未来展望
- **问题解决**：针对特定问题的解决方案

### 2. 灵活写作风格
- **对话式风格**：默认，使用AI导师与开发者对话模式，生动幽默
- **正式技术文档**：严谨专业的技术说明文档
- **通俗科普风格**：通俗易懂适合技术小白
- **学术研究风格**：适合研究人员和技术人员
- **营销推广风格**：适合产品介绍和技术推广

### 3. 智能适应的文章结构
根据文章类型和用户需求，选择最适合的文章结构。

#### A. 教程型结构
```
对话式开篇 → 前置知识 → 准备工作 → 分步实操 → 错误排除 → 扩展应用 → 总结
```

#### B. 概念型结构  
```
问题背景 → 概念定义 → 原理解析 → 实例说明 → 应用场景 → 深入思考 → 总结
```

#### C. 对比型结构
```
背景介绍 → 方案概述 → 详细对比 → 使用场景 → 选择建议 → 实践建议
```

#### D. 案例型结构
```
项目背景 → 需求分析 → 解决方案 → 实现过程 → 效果评估 → 经验总结
```

## 智能写作流程

### 步骤1：内容分析与规划
- **主题识别**：解析用户提供的主题关键词和背景
- **受众定位**：根据主题复杂度判断目标读者水平
- **类型判断**：确定最适合的文章类型和结构
- **风格选择**：基于内容性质选择最佳写作风格

### 步骤2：结构设计与内容框架
- **动态结构调整**：根据主题特点调整文章结构
- **层次内容规划**：确保观点、实例、代码平衡
- **代码示例验证**：生成可靠可执行、有注释提示的代码
- **实例场景设计**：创造真实实际场景的逻辑实例

### 步骤3：内容生成与优化
- **技术准确性**：确保技术细节准确无误
- **逻辑连贯性**：保证文章结构和论证逻辑清晰
- **可读性优化**：增强通俗性、幽默性和重点突出
- **实用价值**：确保读者能够获得实际帮助

- **指定风格偏好**：如"正式文档风格"、"轻松对话风格"

## 自动化执行

当用户提供文章主题时，自动执行以下步骤：

1. **获取写作指导**（如果存在）：
   - 自动读取项目根目录的 `AI_Agent技术写作指导.md`
   - 了解特殊写作要求和风格特点

2. **分析文章需求**
   - 判断文章类型（教程、概念、技术对比等）
   - 确定适合的写作风格（对话式、正式文档、通俗等）
   - 规划文章结构和长度

3. **生成高质量内容**
   - 根据分析选择最佳模板结构
   - 生成符合要求的技术文章内容
   - 确保代码示例、实例应用的实用性

4. **自动保存到文件**
   - 将生成的文章保存为markdown文件
   - 文件命名基于文章标题，使用中文易于识别
   - 保存在当前工作目录下
